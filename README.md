# MemeVaani AI 🎭🇮🇳
> **The AI-Powered Indian Meme & Audio Studio for Creators & Video Editors**  
> Powered by [Sarvam AI](https://sarvam.ai) (`sarvam-105b-conversations`, `bulbul:v3` TTS, and `saaras:v3` STT).

---

## 🌟 Features

- 🧠 **AI Situation-to-Meme Matcher (`sarvam-105b-conversations`)**: Describe any situation in English, Hindi, or Hinglish to get culturally accurate Indian meme templates, dialogue lines, and video editor cut tips.
- 🎬 **Trending Meme Idea Clips Gallery**: Homepage showcase of iconic moments with live GIF animations, punchlines, and instant audio playback.
- ✂️ **Video Clipper & Animated GIF Maker**: Trim any instance from uploaded video clips, overlay meme text, and export looping animated GIFs.
- 🎨 **Meme & Sticker Studio**: Live HTML5 canvas editor with classic Impact font, stock Indian templates, and die-cut sticker mode.
- 🎙️ **Desi Voiceover Generator (`bulbul:v3`)**: Generate native Indian voice reactions across multiple personas and regional languages.
- 🔊 **Viral Indian SFX Soundboard**: Interactive audio board featuring viral dialogues (*Aayein*, *Gaya Khatam*, *Paisa Laya*, *Ye To Tatti Hai*, *Jalwa Hai Hamara*, etc.) and sound effects (*Vine Boom*, *Harmonium*, *Record Scratch*).

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
cd YOUR_REPO_NAME
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Configure API Key
Create a `.env` file in the root directory:
```env
SARVAM_API_KEY=your_sarvam_api_key_here
```

### 4. Run the Application
```bash
uvicorn app:app --reload
```
Open **http://127.0.0.1:8000** in your browser.
